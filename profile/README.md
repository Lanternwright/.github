# Lanternwright

Small tools that run on your own device. A one-person software studio in Columbus, Ohio.

- Site and product pages: https://lanternwright.com
- Support: support@lanternwright.com (a person reads every message)
- Everything here keeps your data on your machine; anything paid is a one-time purchase, and accessibility is never a paid extra.

The public repositories in this organization are the free tools and the open cores of the paid ones. Each README says what it stores, what it sends (usually nothing), and how to build it.
